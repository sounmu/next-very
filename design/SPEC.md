# 마진로그 (MarginLog) - 화면 명세

외식업 사장님용 모바일 앱. 거래명세서/영수증 사진으로 지출을 기록하고, 매출을 입력해 순수익을 보고, 익명 매장들과 매입가를 비교해 더 싼 공급처로 연결한다.

해커톤 시연용 목업이다. 모든 화면은 아래 "공통 시연 데이터"의 숫자를 그대로 써서 화면 간 숫자가 맞아야 한다.

## 프레임 규칙

- 프레임: 390 x 844 (iPhone 14/15), `design/screens/NN-name.html` 한 파일 = 한 화면
- 모든 화면은 `<link rel="stylesheet" href="../tokens.css">` 하나만 쓴다. 외부 CDN, 웹폰트, 원격 이미지 금지. 아이콘은 인라인 SVG.
- 루트 구조: `<body><main class="frame"> ...상태바(.statusbar) / 앱바 / 콘텐츠(.content) / 하단 탭바(.tabbar) 또는 하단 CTA(.bottom-cta) </main></body>`
- 하단 탭(메인 화면만): 홈 / 장부 / 리포트 / 비교 / 공급처
- 언어: 한국어. 금액 표기 `1,234,000원`, 음수는 `-`.
