# 마진로그 (MarginLog)

외식업 사장님을 위한 모바일 장부 + 매입가 비교 앱. 해커톤 시연용 프로덕트다.

거래명세서나 영수증을 찍으면 AI가 품목과 금액을 뽑아 장부에 넣고, 매출을 입력하면 매달 순수익 리포트를 만든다. 같은 지역, 같은 업종의 익명 매장들과 품목별 매입가를 비교해서 더 싸게 파는 공급처로 연결해 준다.

## 핵심 기능

| 기능 | 설명 | 화면 |
|---|---|---|
| 사진 업로드, AI 추출, 수기 수정 | 거래명세서 촬영 → 품목/수량/단가/금액 자동 추출 → 신뢰도가 낮은 칸을 강조해 직접 고치기 | 03, 04, 05 |
| 지출 장부, 매출 입력 | 식자재 분류별(육류/채소/쌀·곡류/양념·소스/유지·기타) 지출 장부와 고정비 합계 한 줄, 채널별(카드/현금/배달앱) 일 매출 입력 | 06, 07 |
| 순수익 추이 리포트 | 월별 순수익 그래프, 순이익률, 식자재 구성, 한 줄 인사이트 | 08 |
| 메뉴 원가 | 메뉴별 식자재 원가율 막대 그래프(업종 중앙값 기준선), 한 메뉴(제육볶음)의 월별 1인분 원가 추이와 재료별 원가 변화 | 13, 14 |
| 익명 구매가 비교 | 동네 동종 매장들의 중앙값, 하위 25% 가격과 내 단가 비교 | 09, 10 |
| 공급처 연결 | 절감액 기준 공급처 추천, 견적/연결 요청 | 11, 12 |

## 폴더 구조

```
design/
  SPEC.md          화면 명세와 모든 화면이 공유하는 시연 데이터
  tokens.css       디자인 토큰(색, 글꼴, 간격, 반경)과 공통 컴포넌트 클래스
  screens/         화면별 HTML 목업 (390x844, 01~14)
  screenshots/     화면별 PNG 렌더 결과
  svg/             화면별 SVG (390x844, 글자는 편집 가능한 <text>, Figma용)
  index.html       전체 화면 갤러리
  VERIFY.md        화면별 시각/수치 검증 결과
AGENTS.md          에이전트/기여자용 작업 규칙
```

## 화면 보기

브라우저에서 `design/index.html`을 열면 14개 화면이 흐름 순서대로 보인다. 화면 하나만 보려면 `design/screens/NN-이름.html`을 연다. 빌드나 서버는 필요 없다.

시연 흐름: 01 온보딩 → 02 홈 → 03 촬영 → 04 AI 추출 → 05 수기 수정 → 06 장부 → 07 매출 입력 → 08 리포트 → 13 메뉴별 원가율 → 14 메뉴 원가 추이 → 09 구매가 비교 → 10 품목 상세 → 11 공급처 → 12 연결 요청

## Figma로 가져오기

이 레포의 화면은 HTML로 만들어져 있다. Figma 파일로 옮기는 방법은 세 가지다.

1. SVG 가져오기 (권장): `design/svg/*.svg`를 Figma 캔버스에 끌어다 놓는다. 화면마다 390x844 프레임 하나가 되고, 도형은 벡터 레이어로, 글자는 편집 가능한 텍스트 레이어로 들어온다. 글꼴은 Pretendard로 지정돼 있어서, Figma에 Pretendard가 없으면 다른 글꼴로 바뀐다. 이때는 Pretendard를 설치하거나 Figma에서 글꼴을 다시 지정한다.
2. 편집 가능한 레이어로 가져오기: Figma 플러그인 html.to.design을 설치하고 `design/screens/*.html`을 가져온다. 로컬 파일은 `npx serve design`처럼 로컬 서버로 띄운 뒤 URL로 넣거나, 플러그인의 HTML 붙여넣기 기능을 쓴다. 프레임 크기는 390x844(iPhone 14)로 설정한다.
3. 이미지로 빠르게 배치하기: `design/screenshots/*.png`를 Figma 캔버스에 끌어다 놓고 프로토타입 연결만 건다.

## 시연 데이터

모든 숫자는 `design/SPEC.md`의 "공통 시연 데이터"에서 온다. 예: 10월 매출 18,420,000원, 지출 14,540,000원, 순수익 3,880,000원, 월 절감 가능액 312,000원. 숫자를 바꿀 때는 SPEC.md를 먼저 고치고, 그 숫자를 쓰는 모든 화면을 같이 고친다.

## 참고

기능 구성은 외식업 원가 관리 서비스 푸드로직(https://www.foodlogic.co.kr/)을 참고했다. 브랜드, 문구, 이미지, 디자인은 이 프로젝트에서 새로 만들었고 푸드로직의 자산을 쓰지 않는다.
